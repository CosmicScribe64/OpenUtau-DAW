a published binary must be provided in the same GitHub release as a source
archive, including this repository, its build and packaging scripts, the
`upstream` OpenUtau source pinned by the repository, and the VST adapter patch.

The upstream OpenUtau code remains available under its MIT licence. JUCE is
used under its AGPLv3 option. Individual bundled dependencies retain the terms
listed in `THIRD-PARTY-NOTICES.md` and `THIRD-PARTY-LICENSES/`.

This development package is not a substitute for the tagged corresponding
source archive. Do not publish a binary release unless its exact source archive
is attached and the archive can reproduce that binary's source inputs.
