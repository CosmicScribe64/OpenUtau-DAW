# OpenUtau DAW v0.1.0-alpha.3

This alpha focuses on the parts of the editor that should feel immediate in a
DAW: auditioning notes, typing lyrics, using shortcuts, and returning to the
same place after closing the plug-in window.

## What changed

- Piano-key audition now starts immediately, releases cleanly, and stays stable
  while a key is held. It still travels through the VST output and the DAW
  mixer.
- Space controls FL Studio except while typing in an OpenUtau text field, where
  it inserts a space normally. Command/Control+Space and F12 remain FL Studio
  shortcuts. OpenUtau keeps undo, redo, selection, and note deletion.
- Backspace edits a focused lyric or text field and deletes selected notes when
  no text field is active.
- Closing and reopening the editor restores its page, active voice part, zoom,
  scroll position, and pane layout. When moving between plug-in instances, each
  instance remembers its own page, part, zoom, and scroll position.
- Resize cursors now remain visible while hovering over pane dividers on macOS.
- Preview buffering no longer causes delayed, crackling, or broken-up piano-key
  tones with large host audio blocks.

The macOS arm64 build was tested by hand in FL Studio 2026 with two OpenUtau
instances, Teto English and Japanese voicebanks, Adachi Rei, mixer effects, and
a separate drum instrument. The container suite also covers 44.1, 48, and
96 kHz rendering with several host block sizes.

## Downloads

- **macOS arm64:** tested in FL Studio 2026 on Apple silicon. Ad-hoc signed and
  not notarized.
- **macOS x64:** experimental Intel build for macOS 14 or newer.
- **Windows x64:** experimental. The packaged editor and VST3 validator tests
  pass; hands-on FL Studio testing is still pending.
- **Linux x64:** experimental native VST3 with a separate editor window.

Every package includes its own .NET runtime. Voicebanks are not included.

## Current limitations

- One embedded OpenUtau editor can be visible at a time. Multiple plug-in
  instances still render, save, and remember their editor views independently.
- Notes are entered in OpenUtau; the plug-in does not accept DAW MIDI input.
- Voicebanks, resamplers, and external models must be installed separately.
- The macOS package is not notarized. Windows, Intel macOS, Linux, and DAWs
  other than FL Studio on Apple silicon still need broader hands-on testing.
