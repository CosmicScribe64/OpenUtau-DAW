# OpenUtau DAW v0.1.0-alpha.2

This is the first downloadable public alpha of OpenUtau DAW, a VST3 instrument
that embeds the full OpenUtau editor inside the DAW. It follows the Synthesizer
V-style workflow: OpenUtau owns singers, lyrics, notes, phonemes, and pitch
editing while the host owns transport, tempo, saving, mixer routing, effects,
and export.

Alpha 2 contains the same tested VST implementation as the initial alpha tag
and corrects release portability issues found by the hosted runners:
authoritative annotated-tag validation, Docker checkout ownership, compatible
Windows editor target frameworks, intentional MSVC cache-line alignment, and
fail-fast Windows build diagnostics.

## Downloads and support status

- **macOS arm64:** verified in FL Studio 2026 on Apple silicon. This community
  build is ad-hoc signed and not Apple-notarized, so follow the targeted
  [macOS installation guide](https://github.com/CosmicScribe64/OpenUtau-DAW/blob/v0.1.0-alpha.2/docs/install-macos.md)
  if macOS quarantines it.
- **Windows x64:** experimental. It builds natively on Windows, opens the full
  editor in a native smoke host, and passes Steinberg's VST3 validator. It has
  not yet completed an audible licensed FL Studio-on-Windows acceptance run.
- **Source:** the complete corresponding-source archive contains this adapter,
  pinned OpenUtau source, pinned JUCE source, build scripts, and notices.

Both binary packages carry their own private .NET runtime. Users do not install
.NET, OpenUtau, Docker, CMake, or an SDK. Voicebanks are not redistributed.

## Highlights

- full resizable OpenUtau workspace embedded in FL Studio;
- host transport, playhead, BPM, and time-signature synchronization;
- DAW-project save and restore of the complete USTX state;
- stereo output through normal FL mixer inserts and effects;
- Japanese and English singing with multiple singers and plug-in instances;
- device-free editor preview routed through the VST output;
- isolated render sidecars with crash, timeout, and missing-resource recovery;
- offline export and sample-rate/buffer-size regression coverage;
- self-contained private .NET runtime—users do not install .NET or an SDK.

## Known limitations

- Only one embedded VST editor can be visible at a time inside one DAW process.
  Multiple processors still render and save independently; close one editor
  before opening another.
- Notes are authored in OpenUtau; the plug-in intentionally does not advertise
  DAW MIDI input.
- Voicebanks, resamplers, and external models are not embedded in the FLP and
  must be installed separately on every machine.
- Intel macOS is not built or tested.
- Windows x64 should be treated as experimental until the retained FL Studio
  render fixture passes on a licensed Windows runner.
- Other VST3 DAWs have not yet completed real-host acceptance.

## Install

- macOS arm64: follow the
  [macOS installation guide](https://github.com/CosmicScribe64/OpenUtau-DAW/blob/v0.1.0-alpha.2/docs/install-macos.md).
- Windows x64: follow the
  [Windows installation guide](https://github.com/CosmicScribe64/OpenUtau-DAW/blob/v0.1.0-alpha.2/docs/install-windows.md).

The macOS archive intentionally ships without Apple Developer ID notarization.
Verify its SHA-256 sidecar before applying the documented bundle-specific
quarantine removal. Never disable Gatekeeper globally.
