# OpenUtau DAW v0.1.0-alpha.2

OpenUtau DAW puts the OpenUtau editor inside a VST3 window. Editing happens in
OpenUtau while the DAW handles transport, saving, mixer routing, effects, and
export.

This release fixes the Windows editor package, bundles the matching Windows
Desktop Runtime, and adds Intel macOS and Linux x64 builds. It also fixes tag
validation and checkout ownership in the release workflow.

## Downloads

- **macOS arm64:** tested in FL Studio 2026 on Apple silicon. The build is
  ad-hoc signed and not notarized.
- **macOS x64:** experimental. Built for Intel Macs running macOS 14 or newer;
  not yet tested in a DAW.
- **Windows x64:** experimental. The packaged editor opens in the smoke host
  and the VST3 passes Steinberg's validator, but it has not completed the FL
  Studio render test.
- **Linux x64:** experimental native VST3. The editor opens in a separate
  window, and the package has not yet been tested in a Linux DAW.

Every package includes its own .NET runtime. Voicebanks are not included.

## Current limitations

- Only one embedded editor can be open at a time in a DAW process. Multiple
  plug-in instances can still render and save independently.
- Notes are entered in OpenUtau; the plug-in does not accept DAW MIDI input.
- Voicebanks, resamplers, and external models must be installed separately on
  each machine.
- Hosts other than FL Studio on Apple-silicon macOS have not completed manual
  acceptance testing.

## Installation

- [macOS](../install-macos.md)
- [Windows](../install-windows.md)
- [Linux](../install-linux.md)

Verify the downloaded archive against its SHA-256 file. On macOS, follow the
bundle-specific quarantine instructions in the installation guide; do not
disable Gatekeeper.
