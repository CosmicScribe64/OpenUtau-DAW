# OpenUtau DAW v0.1.0-alpha.1

This is the first public-alpha release candidate of OpenUtau DAW, a VST3
instrument that embeds the full OpenUtau editor inside the DAW. It follows the
Synthesizer V-style workflow: OpenUtau owns singers, lyrics, notes, phonemes,
and pitch editing while the host owns transport, tempo, saving, mixer routing,
effects, and export.

## Supported release target

- Apple-silicon macOS (arm64)
- FL Studio 2026
- VST3 instrument format

Windows and other DAWs have build/test lanes but are not supported by this
release until their real-host acceptance gates pass.

## Highlights

- full resizable OpenUtau workspace embedded in FL Studio;
- host transport, playhead, BPM, and time-signature synchronization;
- DAW-project save and restore of the complete USTX state;
- stereo output through normal FL mixer inserts and effects;
- Japanese and English singing with multiple singers and plug-in instances;
- device-free editor preview routed through the VST output;
- isolated render sidecars with crash, timeout, and missing-resource recovery;
- offline export and sample-rate/buffer-size regression coverage;
- self-contained private .NET runtime—users do not install .NET or an SDK.

## Known limitations

- Only one embedded VST editor can be visible at a time inside one DAW process.
  Multiple processors still render and save independently; close one editor
  before opening another.
- Notes are authored in OpenUtau; the plug-in intentionally does not advertise
  DAW MIDI input.
- Voicebanks, resamplers, and external models are not embedded in the FLP and
  must be installed separately on every machine.
- Intel macOS is not built or tested.

## Install

1. Quit FL Studio.
2. Copy `OpenUtau DAW.vst3` to `~/Library/Audio/Plug-Ins/VST3/`.
3. Reopen FL Studio and rescan installed VST3 plug-ins if necessary.
4. Add **OpenUtau DAW** as a generator.

The final public archive must be Developer ID signed and notarized. Do not
publish the current ad-hoc-signed development archive as the final download.
